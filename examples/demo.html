threejs-shadow-grid

A configurable, infinitely-tiling grid of 3D objects for site backgrounds - this whole page's background is it, running live. Move your mouse around and watch the shadows follow.

  • Weighted STL model mix
  • Weighted color palettes
  • Grid or randomized layout
  • Sun or cursor-follow light
  • Full-page or contained box
  • Independent size & rotation
  • Soft → hard shadow presets
  • Live config code export
  • Row offset for brick/masonry layouts
  • Auto-fills any container size
  • Framework-agnostic, no React/Vue needed
